Nightlight

Start while off for sunrise, or while on for sunset. Uses WLED's Sunrise effect for 1–60 minutes. Sunset restores the prior effect and turns off; sunrise holds the completed sun. Stop restores the prior effect and keeps power on.

    Configuration

    FPP channel numbers start at 1; virtual pixel indexes start at 0. Each native device must have one control mode. Saved changes take effect after restarting the runtime service.

    Native WLED devices

    Enable discovery in configuration to list mDNS candidates. Enroll an IPv4 address in the devices list and choose effect, sync, or fpp-stream mode. Configure streamed channels in FPP.

    Discovery results appear here.

    Show ownership blocks these commands. Sync mode accepts effect settings; preset IDs require effect mode. Device results appear in status above.

    Effect-mode devices retain ambient lighting checkpoints and retry recovery after realtime input ends. Saved native playlists restart from the beginning. Unsaved playlists and active nightlights cannot yet be restored. Recovery details appear in device status above.

    Custom palettes

    Import a native palette file or edit its JSON. Slot 0 is palette ID 200; subsequent slots count downward. Use 2–18 ordered stops from 0 to 255. Palette colors are RGB; a white component in hex input is ignored as in WLED.

    Import WLED presets

    Merge a WLED presets.json file into this runtime. Matching IDs will be overwritten; other presets remain. Preview checks the current pixel layout and reports translations. Unsupported entries block the whole import. Lighting and show locks remain active.
