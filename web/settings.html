Lights between showsChecking who controls the lights...

Background lighting (also called ambient lighting) is the color or pattern you see when no show is playing. A show always takes priority. When all shows have ended, WLED waits two seconds, then returns to your previous background lighting.

Choose Allow background lighting to let WLED run between shows. Choose Stop background lighting to stop its output. These buttons do not stop an FPP show. If the lights stay dark, open WLED and check its power and brightness controls.

Advanced: shows that send directly to other controllers

Most users can skip this. FPP shows are detected automatically. If a program such as xSchedule sends a show straight to a controller, it must tell this plugin when the show starts and ends. These buttons let you do that by hand.

Enter a name for the show program, such as xschedule:main. Click Show Start before its show and Show End after it stops, using exactly the same name. Until you click End, background lighting stays paused, even after a restart. Each show program needs its own name. For everyday use, set up your show program to send these commands automatically.

Nightlight timer
Nightlight

A one-time timed fade or sunrise/sunset animation. Choose its duration and final brightness, then Start. This does not create a repeating schedule.

Start while off for sunrise, or while on for sunset. Uses WLED's Sunrise effect for 1–60 minutes. Sunset restores the prior effect and turns off; sunrise holds the completed sun. Stop restores the prior effect and keeps power on.

Color fade changes the lights toward the secondary color. The countdown pauses during shows. Applying another look or restarting WLED stops this timer.

Schedules & daylight

Want a favorite look to turn on at a set time? First save that look as a preset in WLED. Then choose its time, preset and days below. Click Add timer, then Preview upcoming events. Check the times and click Save schedules.

Timers start working as soon as you save. If a timer falls during a show, or while background lighting is stopped, it is skipped. It will not run late.

North/east are positive; south/west are negative. The named timezone applies to all timers. Without a location, clock timers use this FPP player's local time.

    Connect your lights

    Import named lights from FPP

    Choose the strings or channel models you want WLED to use. Prefer a matrix model to its individual strings. Do not select both when they use the same channels.

    Preview shows the replacement segments. Save keeps a backup in the plugin data directory; Apply setup below restarts WLED with the new layout. FPP outputs and saved presets are kept. Presets using old pixel ranges may need editing.
    

    This section connects WLED to the lights already set up in FPP. You only need to change it when setting up or adding lights. A pixel is one individually controlled light. WLED creates its colors; FPP sends them to the real lights.
    Set the total number of pixels below. Choose RGB for red/green/blue lights, or RGBW if they also have a separate white LED. Leave the animation speed at 40 frames per second unless you need to change it.
    

    

    For a strip, width equals pixel count and height is 1. For a matrix, width times height must equal pixel count.
    

    FPP channel mappings
    Each row tells FPP where to send a section of lights. Copy the starting channel from that output in FPP. Example: for 100 RGB lights starting at FPP channel 1, enter first pixel 0, pixel count 100, and first FPP channel 1. Those lights use channels 1 to 300.
    WLED counts its first pixel as 0; FPP counts its first channel as 1. Do not send two rows to the same FPP channels. Row changes take effect only after you save and apply the setup.
    

    Other WLED controllers
    Add a controller here only if you want to send it individual commands or manage its output mode. Give it a short nickname, such as porch, and enter its network address, such as 192.168.1.25. Groups are optional names for controllers you want to control together.
    Choose Effects / presets to send a lighting look, Sync to share lighting changes, or FPP pixel streaming if FPP sends its pixel colors. FPP streaming also needs an output set up in FPP. To simply find devices and sync with them automatically, use the next section; you do not need to add them here.

    Find other WLED devices
    Use this section to find other WLED controllers on your home network. Finding a controller does not change its lights. Click its name in the results to open its own controls.
    To find devices: check Find other WLED devices, then click Save discovery & sync. Wait about a minute for names to appear below. Check Let other devices find this player if you want this FPP player to appear on their lists too.
    

    To make lights change together: also check Share lighting changes (sync) and Automatically sync with found devices. Send lets this player lead; Receive lets it follow. Turn on the matching send/receive settings on the other controllers too. Use the same sync group on all of them; group 1 is a good starting point.

    Troubleshooting: a device is missing
    Make sure it is powered on and connected to the same network. Open its WLED page to check it is reachable. Guest networks can prevent devices from seeing each other.
    Discovery stays on the local network; allow UDP 5353, 65506 and your sync port. Native WLED Nodes links open FPP because the node protocol has no web-path field. Use this page's links for the full plugin address.

    Advanced: send a command to another WLED controller
    Controller commands
    Send a one-off ambient command to an enrolled device ID or to group:outside. For example, {"ps":1} recalls preset 1 saved on the target controller, not preset 1 on this FPP runtime. This does not change how the device is enrolled.
    For individual/group preset commands or FPP pixel streaming, enroll an IPv4 address in Outputs & devices and choose effect, sync, or fpp-stream mode. Automatic sync needs no manual enrollment.
    

    Show ownership blocks these commands. Sync mode accepts effect settings; preset IDs require effect mode. Device results appear under Technical details in Lights between shows.
    

    Advanced: restoring other controllers after a show
    Effect-mode devices retain ambient lighting checkpoints and retry recovery after realtime input ends. Saved native playlists restart from the beginning. Unsaved playlists and active nightlights cannot yet be restored. Recovery details appear under Technical details in Lights between shows.
    

    Custom color collections Advanced
    A palette is a collection of colors used by an effect. For everyday use, choose one of the ready-made palettes in WLED. This section is for importing or writing your own palette file. Save it here, then reload WLED and choose it from the palette list. Loading a saved slot only opens it for editing; it does not change your lights.
    

    Import a native palette file or edit its JSON. Slot 0 is palette ID 200; subsequent slots count downward. Use 2–18 ordered stops from 0 to 255. Palette colors are RGB; a white component in hex input is ignored as in WLED.
